### Углубленный когортный анализ (Cumulative ARPU)

Посмотрим, как накапливается доход от клиентов разных когорт.

```r
cohort_arpu <- olist_panel %>%
  group_by(cohort_month, month) %>%
  summarise(
    monthly_revenue = sum(spent),
    cohort_size = first(sum(is_active == 1 & month == min(month))),
    .groups = "drop"
  ) %>%
  arrange(cohort_month, month) %>%
  group_by(cohort_month) %>%
  mutate(
    cum_revenue = cumsum(monthly_revenue),
    cum_arpu = cum_revenue / cohort_size,
    months_since_start = as.numeric(difftime(month, min(month), units = "days")) / 30
  )

# Визуализация
ggplot(cohort_arpu %>% filter(months_since_start <= 12), 
       aes(x = months_since_start, y = cum_arpu, color = as.factor(cohort_month))) +
  geom_line() +
  labs(title = "Cumulative ARPU by Cohort", x = "Months", y = "Cumulative Revenue per User") +
  theme_minimal()
```

3. Если вы построите модель оттока и включите туда risk_scoring_internal, она покажет идеальную точность. Почему это плохо? 

```r
# Модель оттока
# Используем агрегированные данные по клиентам из панели
churn_model_data <- telco_panel %>%
  group_by(customerID) %>%
  summarise(
    tenure = max(month_index),
    avg_arpu = mean(MonthlyCharges),
    total_tickets = sum(num_support_tickets),
    contract_type = first(Contract),
    is_churned = max(is_churned_monthly) # Целевая переменная: 1 - ушел, 0 - остался
  ) %>%
  ungroup() %>%
  mutate(
    # Преобразуем контракт в фактор для регрессии
    contract_fct = factor(contract_type, levels = c("Month-to-month", "One year", "Two year"))
  )

# Логистическая регрессия (предсказание оттока)
churn_logit <- glm(
  is_churned ~ tenure + avg_arpu + total_tickets + contract_fct,
  data = churn_model_data, family = binomial(link = "logit")
)

# Интерпретация через Odds Ratios (экспоненцированные коэффициенты)
odds_ratios <- exp(coef(churn_logit))
print(round(odds_ratios, 3))
# или questionr::odds_ratio + avg_slopes()

# Визуализация влияния контракта на вероятность оттока
ggplot(churn_model_data, aes(x = contract_fct, fill = factor(is_churned))) +
  geom_bar(position = "fill") +
  scale_y_continuous(labels = scales::percent_format()) +
  labs(
    title = "Churn Rate by Contract Type",
    x = "Contract Type",
    y = "Proportion",
    fill = "Churned"
  ) +
  theme_minimal()
```

Диаграмма наглядно показывает, что тип контракта - ключевой фактор удержания. У клиентов на помесячном тарифе доля ушедших самая высокая, при годовом контракте она падает в разы, а при двухлетнем становится совсем небольшой. Это полностью согласуется с результатами регрессии, где годовой и двухлетний контракты резко снижали шансы оттока относительно помесячного. 

Но если в модель оттока добавить переменную risk_scoring_internal, то она покажет почти идеальную точность, поскольку это признак утечки данных. Дело в том, что этот скоринг рассчитывается самой компанией уже с учётом знания о том, ушёл клиент или нет, то есть в нём фактически ЗАРАНЕЕ закодирован тот ответ, который мы пытаемся предсказать. Получается, что модель не учится распознавать факторы оттока, а просто пересказывает уже известный результат, что дает отрицательный вклад практической пользы.

Чтобы оценить эти различия численно, построим модель Кокса (модель пропорциональных рисков) и посмотрим на Hazard Ratio. Hazard - это мгновенный риск, то есть вероятность уйти прямо сейчас при условии, что клиент дожил до этого момента. Hazard Ratio - отношение таких рисков между группами, показывающее, во сколько раз риск оттока у одной группы выше или ниже, чем у другой, в любой данный момент времени. Модель Кокса как раз предсказывает этот риск в зависимости от предикторов (тип контракта, чек, тип услуги и т.д.) и выдаёт HR для каждого из них, поэтому запустим её.

```r
# Модель Кокса 
cox_fit <- coxph(
  surv_object ~ contract_type + MonthlyCharges + is_fiber_optic +
             has_partner + has_dependents,
  data = telco_surv
)
summary(cox_fit)

cox.zph(cox_fit)

```

Проверка cox.zph выявила нарушение допущения пропорциональности рисков (GLOBAL p < 2e-16, и по контракту в частности), поэтому Hazard Ratio следует трактовать как усреднённые по времени, а не строго постоянные, что согласуется с KM-кривыми, где долгосрочные контракты «отпускают» клиентов в основном к концу срока.

Со временем наклон кривой становится более пологим: выжившие клиенты постепенно «закрепляются», и для них риск ухода снижается. У годового и двухлетнего контрактов картина иная - там отток почти отсутствует в начале и концентрируется ближе к концу срока действия договора (клиенты «досиживают» контракт и уходят при его истечении).

2. Что касается типа контракта - это самый мощный фактор удержания. Относительно базового помесячного контракта годовой снижает мгновенный риск оттока на ~86% (HR = 0.14), а двухлетний - на ~98% (HR = 0.02); оба эффекта высокозначимы.
