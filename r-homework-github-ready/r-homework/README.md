## Данные и статус воспроизводимости

В репозитории находятся исходники и пояснения. Входные данные и ранее сформированные отчёты не включены. Данные учебных работ заявлены как синтетические; методы и выводы представлены в учебных целях.

Для запуска нужны локальные файлы, перечисленные в [data/README.md](data/README.md). CSV для работ 2, 4 и 12 отсутствовали в предоставленных архивах. Бинарная база работы 1 не включена; использовать её можно локально либо собрать новую базу из исходных CSV по схеме SQL.

После подготовки к публикации расчёты не запускались: в среде подготовки нет R и полного комплекта входных данных. Интерпретации и численные выводы сохранены из исходных работ, а не получены заново. Сиды сохранены. Версии исходного R и пакетов неизвестны; файл блокировки зависимостей отсутствует.

## Запуск

1. Установите R и необходимые пакеты из [DEPENDENCIES.md](DEPENDENCIES.md).
2. Положите локальные данные в соответствующие каталоги `data/lab-XX/`.
3. Запускайте работу из её каталога, чтобы относительные пути разрешались правильно.

Работа 1, из корня репозитория:

```sh
cd labs/lab-01
Rscript analysis.R
```

Работа 4, из корня репозитория:

```sh
cd labs/lab-04
Rscript -e 'rmarkdown::render("analysis.Rmd")'
```

Для работ 2 и 12 аналогично перейдите в `labs/lab-02` или `labs/lab-12`. Работа 2 по исходным настройкам создаёт PDF: нужны XeLaTeX и шрифты Times New Roman, Arial, Courier New. Работы 4 и 12 создают HTML. Для сборки R Markdown также нужен Pandoc, например поставляемый с RStudio.

Файлы `README.md` внутри каталогов работ — копии исходного текста для просмотра на GitHub, без вычисленного вывода. После изменения R Markdown их нужно обновлять отдельно.

Проверены публикуемые тексты и имена файлов на известные идентификаторы автора, личные пути и распространённые признаки секретов. Это не проверка статистической корректности решений. Публикация в личном аккаунте GitHub связывает репозиторий с этим аккаунтом; очистка содержимого не скрывает владельца профиля.
